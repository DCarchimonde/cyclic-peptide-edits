# B 线模型说明：v0.1 融合骨架

## 本版解决什么

本版先建立可训练的输入、融合和输出接口，方便比较不同信息是否有帮助。它还没有接入真实预训练权重、没有完成通透性训练，也没有证明新的方法优于现有模型。测试中的随机张量只用于检查程序，不能作为生物学结果。

## 输入

`EditAwareFusion` 接收四组二维张量，每一行对应一个完整、身份确定的环肽：

| 参数 | 形状 | 含义 |
| --- | --- | --- |
| `protein` | 批量大小 × `protein_dim` | 蛋白质或肽编码器提供的上下文特征 |
| `chemical` | 批量大小 × `chemical_dim` | 完整化学分子的编码，保留非天然残基、成环连接与手性 |
| `edit` | 批量大小 × `edit_dim` | 外部特征程序明确构建的改造信息 |
| `geometry` | 批量大小 × `geometry_dim` | 可选的构象编码或构象统计特征 |

四组特征应按同一个分子标识对齐，并记录编码器版本与来源。蛋白分支若使用标准残基映射，该映射只是辅助视角，不能替换完整化学结构。改造特征需要确定参考分子和实际改变的原子、键及局部环境；本版不会凭一串序列自动推断这些信息。

## 当前计算过程

蛋白质与完整化学特征分别投影到同一维度，再形成上下文表示。改造特征经过一个受上下文调节的门控分支加入表示；有构象信息时，再加入可选的几何分支。随后通过归一化和线性输出层预测通透性。

这里的“上下文”和“改造”指输入组织方式，尚未保证神经网络学到严格、唯一的共同信息与差异信息分解。门控融合本身也是常见组件，需要通过真实数据上的消融和对照检验作用。

`forward` 返回 `permeability`（每个分子一个标量）及 `embedding`（融合表示）。输出采用训练标签的尺度，例如统一条件下的对数通透系数；它不是百分制药物评分。标签的终点、单位、检测限及训练集变换，应由数据和训练配置记录。

`predict_pair(parent, candidate)` 分别预测两个分子，返回改造体预测减去母体预测。这是变化量任务的简单对照；在推理模式下，交换两者会使差值变号。它尚不是独立训练的改造响应模型。

## 可选构象的含义

`geometry=None` 会跳过几何分支。实际部署时，无构象版本应单独训练和评价，不能把一个只在完整构象上训练的模型直接视为已适应缺失构象。本版读取的是已有特征，并未实现从化学结构生成构象，也未实现原子坐标到几何特征的编码器。

## 下一步接入顺序

先固定一种通透性终点并准备真实分子与划分；接入可复现的预训练特征缓存，训练普通融合和化学信息对照；再根据实际可用改造对开发变化量监督。多环境构象编码作为后续变体加入。
