# 水相与正己烷构象描述符的位点排序消融

固定留出测试中，有 216 个母体组同时具备母体及全部候选的构象描述符，均来自 Kelly。这些组上，水相特征带来的首选损失下降为 0.00315，而加入两个环境后的损失比 2D 高 0.00118。

| 完整选项集上的方法 | 首选损失 | 首选命中率 | Δ MAE |
|---|---:|---:|---:|
| 等概率选择 | 0.25951 | 47.03% | — |
| 2D | 0.23285 | 49.61% | 0.38473 |
| 2D 加水相 | 0.22970 | 52.08% | 0.38090 |
| 2D 加水相和正己烷 | 0.23403 | 48.61% | 0.38158 |

增量误差来自测试的 1,011 个可定量母子对。完整数据中，3,410 个可定量编辑中的 3,196 个有母子两份模拟数据，1,112 个排序组中的 652 个有母体和所有选项的两环境特征。附加逐系列留一评估使用四个有 Δ 的系列，其中三个贡献完整排序组。按母体等权，2D、水相、双环境首选损失为 0.20396、0.21489、0.20106。双环境相对 2D 的差值为 −0.00290，按三个系列配对重采样得到描述性 95% 区间 [−0.02579, 0.00854]。

若母体没有构象，仍可利用 2D 母体和变体特征，只给变体增加相应溶剂向量。该分析在 variant_only 目录，覆盖固定测试中的 458 个 Kelly 排序组，三臂首选损失为 0.22847、0.22814、0.23072。另一项按 Kelly 实验原表恢复 41 个有限正值的分析见 results/pairs/kelly_source_audit。

## 复跑

```bash
python scripts/conform_ablation.py
python scripts/conform_ablation.py --variant-only
```

两条命令均读取冻结的 results/pairs/edits.csv 和已保存的 4D CSV。5,160 个模拟记录的分子 ID、原始 SMILES、来源与 PAMPA 均与快照一致，合计 5,140 个独立精确立体结构。20 个分子有多个不同的模拟摘要，对其不同数值向量等权平均。在 RDKit 的完整手性分子 Morgan 计数、12 个描述符和编辑氮邻域 Morgan 计数基础上，以编辑的母体及变体与母体的差值拟合相同的 160 树 ExtraTrees 回归。水相有 7 项、正己烷有 6 项。按分子分折，以实测编辑 Δ 为标签。源作者的代表帧编号只标识轨迹位置，未作为预测特征。

逐编辑预测和逐母体结果分别在 predictions.csv 和 parent_metrics.csv，逐系列分母和指标在 series_metrics.csv。固定测试只有一个覆盖系列，因此跨系列不确定性留空。另附 bootstrap 重采样的方法差和运行时间。全部消融使用已发布的溶剂描述符，本轮没有新增分子动力学轨迹。数据及定义见 [研究论文](https://doi.org/10.1038/s41597-026-07984-9)、[Zenodo v3](https://doi.org/10.5281/zenodo.21274695)和[固定代码版本](https://github.com/Gobliu/CycPeptMPDB-4D/tree/5772a0b3d013ebd7c1f2c0768cf90a5705d59fe5)。
